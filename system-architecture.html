SkillVista Enterprise AI Architecture

End-to-End Capacity Building Engine for MoSPI Officials & iGOT Karmayogi

SkillVista bridges the gap between civil service competency frameworks (FRAC) and digital learning ecosystems (iGOT Karmayogi). By leveraging Google Gemini 1.5 LLM models, vector search algorithms, and MongoDB storage, SkillVista offers real-time skill-gap diagnosis and automated quiz generation.

Layer 1 · Presentation

Frontend Workspace

Vanilla JS + CSS3 Design System tailored for government portals with glassmorphism, responsive navigation sidebar, and instant preloader splash.

  • • Multi-page static architecture
  • • Chart.js Radar & Progress Visualizations
  • • PDF.js Client-side Document Parser
Layer 2 · AI & Assessment Engine

Gemini AI & FRAC Vector

Computes 4-domain competency scores (Statistical, Technical, Digital Gov, Behavioural) and dynamically ingests training manuals for MCQ generation.

  • • Gemini 1.5 Flash Model Integration
  • • Automated Gap Vector Computation
  • • Contextual Citation & MCQ Generator
Layer 3 · Integration & Data

iGOT Hub & MongoDB

Connects to 1,500+ government courses on igot.gov.in and persists user sessions, assessments, and progress in MongoDB Atlas.

  • • Express.js REST API Server
  • • MongoDB User & Progress Collections
  • • Live iGOT Deep Links & SSO Mock
